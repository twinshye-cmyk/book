# 우리 반 독서 기록장 — 서버 배포 버전

학생은 학번·이름·책 제목·작가·감상문을 제출하고, 교사는 비밀번호로 로그인하여 검색·확인·휴지통 이동/복원 및 XLSX/PDF 다운로드를 합니다. 기존 Flask ZIP의 요구사항을 Cloudflare Workers + 영구 D1 데이터베이스로 옮긴 버전입니다. GitHub Pages에서는 이 서버를 실행할 수 없습니다.

## 기능과 보안

- 감상문은 공백 포함, 앞뒤 공백 제거 후 유니코드 문자 기준 200~10,000자. 서버와 화면에서 함께 검사합니다.
- 교사 비밀번호는 4~128자. HMAC 서버 비밀값 + 무작위 salt + PBKDF2-SHA256 100,000회 해시를 저장합니다. 비밀번호 원문은 저장하지 않습니다.
- 로그인/초기 설정은 IP당 15분에 5회, 전체 30회까지. 제한 횟수는 D1에 저장하여 재시작/서버 분산 후에도 유지됩니다.
- 무작위 256비트 세션 토큰의 해시를 D1에 저장합니다. Secure·HttpOnly·SameSite=Strict 쿠키, 2시간 절대 만료, Origin/CSRF 검사를 적용합니다.
- 비밀번호 변경 시 전체 기존 세션을 폐기합니다. 최초 관리자 등록에는 별도 무작위 초기 설정 키가 필요하며 한 번만 가능합니다.
- 학생 제출은 익명이지만 교사만 제출 목록과 파일을 열 수 있습니다. 실제 학생 데이터는 테스트에 사용하지 않았습니다.
- 휴지통 이동은 복원할 수 있습니다. 현재 영구 삭제/자동 보존 만료 기능은 없습니다. 운영자는 보존 기간과 영구 삭제 절차를 별도로 정해야 합니다.
- 검색 결과는 25건씩 표시하며 내보내기는 한 번에 300건까지이며 PDF는 감상문 합계 50,000자까지입니다. XLSX의 학생 입력은 수식이 아닌 문자열입니다. PDF에는 한글 글꼴이 포함되며 미지원 이모지는 네모로 표시됩니다.

## 설치 및 확인

Node.js 22.13 이상을 사용합니다.

```sh
npm ci
npm run prepare-font
npm run check
npm test
npm run build
```

다운로드 ZIP에는 공개 Noto Sans KR 글꼴과 생성된 모듈이 포함되어 있습니다. GitHub 소스에서 처음 실행할 때는 `prepare-font`가 공개 글꼴과 라이선스를 준비합니다. 실제 비밀값과 데이터는 ZIP/GitHub에 포함하지 않습니다.

## Sites 호스팅

`.openai/hosting.json`에는 이미 이 채팅에서 만든 사이트 ID와 `DB` 바인딩이 있습니다. 같은 사이트로 이어서 배포하며 새 사이트를 중복 생성하지 마세요. `drizzle/`의 스키마 전용 마이그레이션을 배포 시 적용합니다. D1은 브라우저나 서버 임시 디스크 대신 사용되는 영구 데이터베이스입니다.

호스팅 환경에 아래 값을 비밀값으로 등록해야 합니다.

1. `AUTH_PEPPER`: 무작위 32바이트 이상. 초기 설정 후 임의 교체하면 기존 비밀번호로 로그인할 수 없으므로 안전하게 보관합니다.
2. `SETUP_KEY_HASH`: 소유자에게만 전달할 무작위 초기 설정 키의 SHA-256 해시. 초기 설정 키 원문은 저장소에 올리지 않습니다.
3. `APP_ORIGIN`: 실제 HTTPS 주소의 origin. 경로나 마지막 `/`를 붙이지 않습니다.

공개 학생 제출을 사용하려면 Sites의 방문자 범위를 공개로 설정해야 합니다. 서버의 교사 인증은 별도로 계속 적용됩니다. 사이트 공개 전에는 실제 학생 데이터를 입력하지 마세요.

## 관리자 초기 설정

`/teacher`에 접속하여 전달받은 초기 설정 키와 4자 이상의 새 비밀번호를 입력합니다. 등록 후에는 교사 비밀번호만으로 로그인합니다. 관리 화면에서 비밀번호를 변경할 수 있습니다.

비밀번호를 분실한 경우 임의 공개 초기화 기능은 없습니다. 사이트 소유자가 호스팅 관리 권한으로 `admin` 행의 해시를 새로 설정하고 `sessions`를 비우는 복구가 필요합니다. 비밀값 `AUTH_PEPPER`를 교체하는 경우에는 관리자 비밀번호 해시도 함께 재설정해야 합니다.

운영 데이터의 백업/복구는 Sites의 데이터베이스 관리 범위와 D1 제공 정책을 확인하세요. 앱의 XLSX는 백업 보조용이며 전체 인증 상태를 복구하는 데이터베이스 백업은 아닙니다.

## 로컬 미리보기

`.dev.vars`에 테스트용 비밀값과 `APP_ORIGIN=http://localhost:8787`을 설정합니다. 실제 운영 비밀값을 사용하지 마세요. 빌드 후 README에 설명된 Wrangler 로컬 D1 명령으로 `drizzle/0000_reading_journal.sql`을 한 번 적용하고 `npm start`를 실행합니다. 로컬 데이터와 운영 D1은 별개입니다.

`npm test`는 메모리 SQLite에 가상학생만 넣어 테스트합니다. 생성되는 테스트 자료는 `.sites-runtime/` 아래에만 있습니다.
